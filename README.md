## 📌 Highlighted Projects

**OceanCloud** — 웹·모바일 SaaS 정기 검증 & 자동화
Playwright 기반 Page Object Model로 Smoke 테스트 자동화 설계, AI Agent로 TC 선별·리포트 정리 → 검증 소요 시간 0.5일 → 5분 내외로 단축 (약 98%)

**InfVerifyTool** — Windows INF 드라이버 검증 자동화 (Python · PyQt5)
cmd 기반 반복 검증을 드래그 앤 드롭 GUI로 전환, 휴먼 에러 제거 및 결과 요약·복사 자동화 → 검증 소요 시간 약 70% 단축

**EasyCanvas-Multiverse** — 드로잉 앱 & Wacom SDK 검증
FPS·레이턴시·리소스 등 성능 지표 측정 및 색상 정확도 평가, 3D 프린터로 간이 로봇팔을 제작해 환경 영향 없는 표준 테스트 환경 구축

**WHCP Certification** — Windows 하드웨어 인증
USB·모니터(EDID) 등 Multi-OS 호환성 인증 진행, 로그·.inf 파일 분석으로 이슈 원인을 펌웨어로 특정

**Escape for Win** — OEM 파트너 Windows 하드웨어 Initial 인증
USB 드라이버 기능을 127개 TC(30개 스위트)로 관리, 14개 OS Initial 하드웨어 인증 완수
